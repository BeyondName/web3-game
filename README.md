# Web3 Game

Simple demo app that connects a wallet, stakes ETH for matches and ends games on-chain.

## Setup

1. Copy `.env.example` to `.env` and fill in `VITE_CONTRACT_ADDRESS` and `VITE_CONTRACT_ABI`.
2. Install dependencies with `npm install`.
3. Start the development server with `npm run dev`.

## Environment

- `VITE_CONTRACT_ADDRESS` - deployed contract address
- `VITE_CONTRACT_ABI` - JSON encoded ABI for the contract

## Scripts

- `npm run dev` - start Vite dev server
- `npm run build` - build for production
- `npm test` - run placeholder tests
